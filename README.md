# ไทเป ทริป

เว็บแผนเที่ยวไทเป 10–13 ธ.ค. 2026 ใช้บนมือถือ ติดตั้งเป็นแอปได้ ใช้ออฟไลน์ได้

- แก้ข้อมูลทริปที่ `trip.json` ที่เดียว แล้วรัน `python3 build.py` (ต้องมี Pillow และรัน `npm i` ในโฟลเดอร์ `vendor` ครั้งแรก)
- ผลลัพธ์อยู่ใน `docs/` ซึ่ง GitHub Pages ใช้แสดงผล
- รูปจาก Wikimedia Commons (เครดิตใน `photos/photos.json` และท้ายหน้าเว็บ)
